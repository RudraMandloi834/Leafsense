# LeafSense Screenshot Guidelines & Placeholders

This directory is designated for repository visual assets and documentation screenshots.

> **Note for Repository Maintainers:** To ensure complete transparency, no fabricated or simulated screenshots are included in the repository. Maintainers should capture and save actual screenshots of the running application using the filenames listed below.

---

## Required Screenshots

| File Path | Description | Recommended Dimensions | Notes |
|:---|:---|:---|:---|
| `docs/images/dashboard.png` | Main landing interface showing the foliage drag-and-drop zone and camera trigger | 1920 × 1080 px | Capture in light and dark mode |
| `docs/images/diagnosis.png` | Disease detection results showing multi-disease confidence scores and pre-flight quality check | 1920 × 1080 px | Run with a sample infected leaf image |
| `docs/images/gradcam.png` | Color-coded Grad-CAM heatmaps showing localized attention regions | 1920 × 1080 px | Showcase individual and combined overlays |
| `docs/images/ai-assistant.png` | Smart Farming Assistant chat drawer with reasoning summary and verified citations | 1080 × 1440 px | Open consultation with attached prediction |
| `docs/images/hindi-chat.png` | Chat Assistant active in Hindi (`हिं`) demonstrating multilingual advisory | 1080 × 1440 px | Show multi-turn Hindi conversation |

---

## Capture Recommendations

1. **Resolution:** Use standard 1080p browser viewport (1920 × 1080) for desktop views.
2. **Format:** PNG with compression (lossless).
3. **Data Privacy:** Ensure no local paths, development tokens, or internal IP addresses appear in screenshots.
4. **Consistency:** Ensure the LeafSense header, theme toggle, and assistant buttons are clearly visible.
